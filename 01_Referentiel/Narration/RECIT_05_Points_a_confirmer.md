## Mode d'emploi
Registre collaboratif pour Olivier, Thierry et la rédaction. Une réponse peut être : confirmée (avec source ou souvenir concordant), incertaine, ou non retrouvée. Ne pas bloquer la rédaction pour un détail secondaire. Les questions du corpus sont reformulées, sans inventer de réponse.

Conserver les identifiants Qxxx même après résolution. Renseigner le journal des réponses avant de cocher une question confirmée ; une réponse incertaine reste ouverte. Indiquer le fichier et la section de référence lorsque disponibles.

## Règle de validation
Une réponse confirmée doit être répercutée dans le manuscrit et les référentiels concernés, notamment les fiches individuelles YAML + Markdown lorsqu'un personnage est concerné. Vérifier aussi les conséquences sur les illustrations et la continuité visuelle. Une validation graphique ne vaut pas validation narrative.

Les versions Git permettent de conserver l'historique ; ne pas laisser une ancienne hypothèse contredire une correction validée. Consigner les corrections dans le journal, puis mettre à jour les fichiers concernés et conserver l'identifiant de la question. Les modifications du dépôt peuvent désormais être réalisées directement par ChatGPT, un fichier à la fois, sur accord de l'utilisateur ; celui-ci récupère les modifications par git pull.
